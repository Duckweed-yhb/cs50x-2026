# CS50x 2026 问题集 0（Pset0）作业存档

## 一、项目说明
本文件夹为哈佛 CS50x 2026 公开课 Problem Set 0 作业，基于 MIT Scratch 平台完成交互式项目，仅提交核心 `.sb3` 工程文件，**自愿项自我介绍视频未录制提交**。

## 二、作业硬性完成要求
已全部满足官方规定的5项强制条件：
1. 使用至少 2 个精灵角色，其中一个非 Scratch 默认小猫角色；
2. 编写不少于 3 组独立运行的脚本程序；
3. 代码中包含**条件判断语句、循环结构、变量**三种核心逻辑积木；
4. 自行创建至少 1 个带输入参数的自定义积木，实现代码抽象封装；
5. 项目整体复杂度高于课堂基础演示案例，结构拆分合理。

### 未完成可选任务
Hello World 1–2 分钟自我介绍短视频为课程可选加分项，本次不予提交。

## 三、提交流程记录
1. 填写 CS50 官方 Pset0 收集表单；
2. GitHub 账号授权 CS50 Submit 第三方应用权限；
3. 在 `submit.cs50.io` 平台上传 `.sb3` 文件，通过 `check50` 工具校验合规性；
4. 截止时间：2027年1月1日 上午7:59（GMT+8 北京时间）。
